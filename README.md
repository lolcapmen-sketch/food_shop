# food-shop

Один проект: сервер и страницы. Сервер отдаёт `public/` и API с одного адреса, поэтому фронт ходит в `/api/...` без CORS и без настройки адреса.

## Запуск

Нужен Node.js 22.13 или новее. Зависимости ставить не нужно: сервер использует только встроенные модули (`node:http`, `node:sqlite`).

```
npm start
```

Откройте http://127.0.0.1:3000. При первом запуске создаются меню, четыре учётные записи сотрудников (`admin@`, `manager@`, `cook@`, `courier@shop.local`) и случайные пароли. Пароли печатаются в консоль один раз. Чтобы создать их заново, остановите сервер, удалите папку `data/` и запустите снова.

Переменные окружения (все необязательные): `PORT` (3000), `HOST` (127.0.0.1, для Docker или сервера укажите 0.0.0.0), `DATA_DIR` (папка базы), `AUTH_SECRET` (секрет подписи токенов; если не задан, генерируется и хранится в `data/.secret`).

## Структура

```
server/index.js   маршруты API, авторизация, раздача статики
server/db.js      SQLite: схема, начальные данные, хэширование паролей
public/           страницы и js/css (адреса API — в public/js/config.js)
data/             база и секрет (создаётся при запуске, в git не попадает)
```

## Страницы

| Страница | Кто | Что делает |
|---|---|---|
| `index.html` | все | меню, корзина, вход и регистрация покупателя |
| `checkout.html` | покупатель | корзина и точка доставки на карте (Leaflet/OSM) |
| `account.html` | покупатель | профиль, баллы, предложить рецепт |
| `staff-login.html` | персонал | вход, переход по роли |
| `manager.html` | manager, admin | заказы и смена статуса |
| `cook.html` | cook, admin | активные заказы (подтверждён, готовится) с рецептами |
| `courier.html` | courier, admin | заказы в доставке, отметка «Доставлен» |

Роль admin открывает `manager.html`, отдельной страницы администратора нет.

## API

| Метод и путь | Доступ |
|---|---|
| `POST /api/auth/register`, `POST /api/auth/login` | открыт |
| `POST /api/auth/staff/login` | открыт, пускает только сотрудников |
| `GET /api/products` | открыт |
| `GET`, `PUT`, `DELETE /api/users/me` | любой вошедший (удалить себя может только покупатель) |
| `POST /api/recipes/suggestions` | любой вошедший |
| `POST /api/orders` | любой вошедший; цены берутся из базы, а не от клиента |
| `GET /api/manager/orders`, `PATCH /api/manager/orders/:id/status` | manager, admin |
| `GET /api/cook/orders/active` | cook, admin |
| `GET /api/courier/orders`, `PATCH /api/courier/orders/:id/done` | courier, admin |

Ошибки приходят как `{ "message": "..." }`. Баллы: 1 за каждые 100 ₽, начисляются один раз, когда заказ становится «Выполнен».
